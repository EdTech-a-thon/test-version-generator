# Exam Record 0.1.0 fixtures

- [`schema.json`](schema.json) is a version-pinned copy of the public schema whose
  stable identifier is `https://testparrot.com/formats/exam/0.1.0/schema.json`.
- [`examples/`](examples/) contains conforming Exam Records. An Exam Record is
  importable only inside a Test Parrot Package; `unit-test.json` is the Exam
  carried by [`../../package/0.1.0/examples/bank-and-exam.json`](../../package/0.1.0/examples/bank-and-exam.json).
- Invalid counterexamples are with the package, in
  [`../../package/0.1.0/invalid/`](../../package/0.1.0/invalid/).

The prose contract is in
[`docs/exam-record-0.1.0.md`](../../../../docs/exam-record-0.1.0.md).
