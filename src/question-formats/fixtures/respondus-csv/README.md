# Respondus CSV fixtures

- `sample.csv` — written for Test Parrot to Respondus's documented column order
  ("Importing Tab/Comma Delimited Files (CSV)", Respondus Campus 3.5 guide as
  hosted by SIUE: <https://www.siue.edu/its/bb/fac_staff/pdf/respondus_csv_format.pdf>):
  Type, Title/ID, Points, Question Wording, Correct Answer, Choice 1–10, … It has a
  header row (Respondus lets the teacher skip header rows) and one question of each
  type, with correct answers written as a letter, a number, `true`, and a quoted list.
  No file exported by Respondus itself was available.
