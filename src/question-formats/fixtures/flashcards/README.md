# Flashcard fixtures

Written for Test Parrot to the documented export formats; no real exports were available.

- `quizlet-tab.txt` — Quizlet's default export: term, a tab, the definition, one card per line
  (Quizlet Help, "Exporting your sets").
- `anki-export.txt` — Anki's "Notes in Plain Text" export with the file headers Anki 2.1.54+
  writes (`#separator:`, `#html:`, `#deck:`, `#tags column:`), including a cloze note
  (Anki manual, "Importing: Text files").
