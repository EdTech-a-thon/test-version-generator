# Blackboard package fixtures

- `oc-sample-output.zip` — the `sampleOutput.zip` shipped with the Blackboard
  Test Generator's source (Oklahoma Christian University / College of Southern
  Idaho QuizParser), unchanged. That repository is GPL-3.0; the file is the
  tool's own output for `sampleQuiz.txt`, kept here as test data.
- `qti-pool.dat` — hand-written in the shape of a Blackboard Learn pool export
  (`assessment/x-bb-qti-pool`), one item of each type. Not a real export.
