# Brightspace (D2L) question CSV fixtures

- `sample-question-import.csv` — D2L's official sample, unchanged, downloaded
  from <https://s.brightspace.com/apps/import-quiz-questions/1.39.1/sample/Sample_Question_Import_UTF8.csv>
  (the file Brightspace's "Import Questions" page links to). It holds one question of
  each of the seven types: WR, SA, M, MC, TF, MS and O.
