# Share Question Banks across mutable Exams

Question Banks and Exams are independent, many-to-many resources: each Question belongs to exactly one Question Bank, while an Exam may hold live references to Questions from any number of banks and a bank may therefore contribute to any number of Exams. Confirmed Question Bank changes commit before becoming visible everywhere; banks have no separate Working Copy or Save action. Questions are created only in their active Question Bank and are added to an Exam separately; one Question identity occurs at most once per Exam, while Duplicate creates a new Question in the original's bank. Manual Replace accepts any unused Question in the same Question Section; it keeps the outgoing reference's position and answer-column setting while taking the incoming Question's authored answer order. Automatic replacement by equivalence is not offered. Question Type is fixed at creation. Exam-specific answer order and answer-column layout belong to the Working Copy rather than the Question; available column settings are 1, 2, and 4. Question edits preserve arrangement while stable choice identities remain unchanged, but adding or removing choices resets every referencing Exam to the complete authored answer order without dirtying those Exams. Removing a Question clears its Exam-specific presentation state. An inserted Multiple Choice Question begins with its authored answer order and takes the column setting of the Question immediately above it, or immediately below when it has no Question above; with no neighboring Multiple Choice Question it uses one column. Saving updates a mutable Exam, while Save As creates an independent Exam with the same live Question references and no formal version-family relationship. Exams themselves cannot be deleted. Because live Question edits intentionally flow into every referencing Exam, impact is shown in the Question editor and from the home-screen usage view, but not on rows in the editor's Question Bank panel; ordinary edits need no confirmation. Permanently deleting a Question is available from its full editor, not its compact bank row. An unused Question receives a lightweight irreversible confirmation; a used Question first identifies affected Exams and, after explicit confirmation, atomically removes the Question from all of their saved states and Working Copies, clears affected Undo histories, and leaves unrelated changes and immutable Export Records unchanged; failure changes nothing. Deleting a Question Bank applies that same atomic confirmed cascade to every Question it owns, closes affected editors and tabs after commit, and has a lighter but still irreversible confirmation when empty. Bank deletion is available from Home and the full collection, not the editor pane; a bank-only workspace falls back to another open bank or the no-bank state after deletion. Moving Questions between banks remains future scope. Media Assets are garbage-collected only when no Question, saved Exam, Working Copy, or Export Record references them.
