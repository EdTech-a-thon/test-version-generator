# Box Blockquotes, and lay Panels side by side

Converted tests lost two things their pages said. A history packet sets each source passage inside a black border, and the conversion kept the words but not the box. A precalculus test sets two graphs, two tables or a table beside a graph across one line, and the conversion stacked them, because nothing in a question could stand beside anything else.

**A Blockquote prints boxed.** Every Blockquote, in print, PDF and DOCX, is drawn inside a black border, and the editor draws it the same way. We did not add a Box node, and we did not make the box a one-cell table. A passage in a table cell cannot hold the bullet list the history packet's passages hold, and would read as a table to the Export Fingerprint and to an assistant converting a test. A Box node would have meant a new record node, editor node and adapter mapping for something the format already has: the conversion instructions already put a Multipart question's passage in a `blockquote`. The cost is that a quote can no longer be only indented; on a test, a quoted source set apart is what a teacher wants. The name stays Blockquote. Its "Source: …" line is the ordinary paragraph after it, not part of it. In DOCX a Blockquote is a one-cell table, because Word joins paragraph borders into one box only while every paragraph has the same indents, and a list does not.

**A Side-by-Side lays two or three Panels across a stem.** It is its own node, `side-by-side` holding `panel`s in Question Bank Record 0.6.0, and `sideBySide` holding `sideBySidePanel`s in the editor. We did not use a borderless table. A table is something a student reads, with rows and cells. A Side-by-Side is how a stem is laid out, and a Panel holds any block a stem can, which a table cell cannot. The Panels are equal, and there are no widths, alignments or borders to set. A Panel centres its pictures and tables and leaves its text left-aligned, and the Panels are centred against the tallest. A picture's Authored Image Size is relative to its Panel, and a picture resolved from a Source Document fills its Panel. A Side-by-Side goes only directly in a stem, a Question's or a Part's. It never goes in an answer, a Blockquote, a table or another Side-by-Side, and it is never split across a page. Answer choices laid out in a grid are still the Multiple Choice answer columns (ADR-0011). The editor refuses a change that would put a Side-by-Side anywhere else, and one left with a single Panel becomes that Panel's blocks.

Parity reads both as what they are. The Export Fingerprint has `box`/`/box` and `side:<n>`/`panel:<i>`/`/side`. DOCX marks its two tables with the `Blockquote` and `SideBySide` table styles, so they read back as a box and as Panels rather than as tables the teacher wrote.
