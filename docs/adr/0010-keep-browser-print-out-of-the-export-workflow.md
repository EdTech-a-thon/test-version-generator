# Keep browser Print out of the export workflow

Direct browser Print bypasses clean preview, atomic Export Record persistence, and exact re-export, so it will not be a user-facing export path; Cmd/Ctrl+P routes the active non-empty Exam into Export and suppresses native Print. The print Export Adapter remains as an internal reference and testing path while product export produces explicit PDF or DOCX artifacts from the same stored Layout Plans. While viewing Export History, re-export remains an explicit action on the selected record rather than a Cmd/Ctrl+P shortcut.
