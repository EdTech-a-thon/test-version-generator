# Track immutable Question Revisions

Question Revision history captures distinct exported presentation states, not every intermediate edit: export reuses an exactly matching revision and creates an immutable revision only when that Question Bank record's Question Content, correctness, or answer-column layout has not been captured before, while ordinary Question Bank editing remains mutable. Difficulty and Topics are composition utilities rather than revision identity; Exam Draft question order, answer order, and membership likewise remain arrangement concerns. Each Version retains the exact revisions it exported for historical viewing and re-export. Before a historical Version can initialize an Exam Draft, Question Reconciliation explicitly reviews every presentation difference with an expandable old-versus-current comparison: using the latest bank state accepts that complete Question Revision, while keeping historical content forks the complete historical revision into a new Question Bank record. When the choice set is unchanged, the historical Exam Draft answer order survives; when choices were added or removed, using latest takes the complete latest authored order rather than synthesizing a hybrid; keeping historical retains both its authored question state and the Version's answer order. When the source record is absent, reconciliation creates a fresh Question Bank identity from the full historical snapshot; a deleted identity is never resurrected, and the editor contains only current Question Bank records, never stale Question Revisions.
